# Расчёт стоимости, версия 60

Цена сохраняется из того же расчёта, который клиент видит перед отправкой. Повторная синхронизация формы не меняет готовую цену. При смене маршрута, дома, категории или коэффициента старый расчёт становится недействительным.

- Белоусовка: 800 ₸ до 2 км, далее 120 ₸/км; действующий коэффициент и округление вверх до 10 ₸.
- Известный межгород: утверждённый прайс имеет приоритет в обоих направлениях. Например, Белокаменка ↔ Белоусовка — 3500 ₸ за легковой автомобиль. Автоматический коэффициент спроса и расчёт километража эту цену не заменяют.
- Для маршрута с остановками складываются только реально заданные участки прайса. Неизвестный участок или маршрут между двумя внешними населёнными пунктами переводит весь расчёт на километраж; воображаемый заезд через Белоусовку не добавляется.
- Межгород без прайса: 230 ₸/км по дорогам, действующий коэффициент, округление вверх до 50 ₸.
- Надбавка категории автомобиля применяется один раз поверх базовой цены.
- Если городской маршрут временно недоступен, диапазон базового тарифа показывается до оформления и сохраняется без изменений. Если межгород без прайса рассчитать нельзя, отправка заблокирована и доступен звонок диспетчеру. Диспетчер согласует сумму и оформляет заказ через существующую форму с числовой ценой. Заявка с неизвестной стоимостью автоматически не создаётся.
- Комиссия берётся по индивидуальной ставке водителя (0–100%). Ставка фиксируется при принятии/назначении заказа и применяется один раз при завершении. Для диапазона база комиссии — верхняя граница. 0% комиссии допустимы; нулевая стоимость заказа недопустима.

## Публикация защиты Firebase

Обновление GitHub Pages публикует интерфейс. Новые проверки серверных правил требуют отдельной публикации в проект `taxiuspeh-76d55`. В авторизованном Google Cloud Shell из свежей копии основной ветки:

```bash
bash scripts/deploy-pricing-rules.sh
```

Скрипт публикует только Firestore Rules. Firebase Functions и существующие данные он не меняет. Старые заказы автоматически не переоцениваются, списанные комиссии не пересчитываются. Пока правила не опубликованы, старые версии клиента всё ещё могут записывать нулевую стоимость; обновлённые кабинеты блокируют её принятие и завершение.

## Проверка

1. На городском маршруте дождаться расчёта, записать сумму и оформить заказ. Сумма/диапазон в карточках клиента, водителя и диспетчера должны совпасть.
2. Белокаменка → Белоусовка и обратный маршрут: 3500 ₸ за легковой автомобиль.
3. Для направления без прайса при недоступном маршруте заказ не отправляется; видна ссылка для звонка диспетчеру.
4. При ставке 15% и цене 1040 ₸ комиссия — 156 ₸; при 0% — 0 ₸. Изменение ставки уже после принятия заказа не меняет комиссию этой поездки.

Автоматические проверки: `npm run check`, DOM-проверки в `tests/firestore`, финансовые проверки с локальным эмулятором Firestore. Для проверки не следует создавать реальные заказы пассажирам.
