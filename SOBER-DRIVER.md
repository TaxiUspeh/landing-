# Трезвый водитель — онлайн-заказ

Расчёт от базовой точки Белоусовки (50.132, 82.533):

1. Такси от базы к автомобилю клиента — опубликованный тариф направления, иначе дорожное расстояние по обычному тарифу. Применяется текущий коэффициент такси.
2. Перегон автомобиля клиента через все указанные остановки — 230 ₸ за дорожный километр, округление вверх до целого тенге.
3. Такси от конечного адреса к базе — тот же порядок расчёта обычного такси, в обратном направлении.

Общий минимум — 3 800 ₸. При меньшей сумме трёх участков разница добавляется к оплате перегона. База — расчётная точка, а не местоположение назначенного водителя; фактическая стоимость стороннего такси может отличаться.

«Предложить свою цену» работает и при недоступном геокодере/маршрутизаторе. При готовом расчёте предложение не ниже расчёта; при неизвестной стоимости — от 3 800 ₸ до настроенного лимита. Поздний расчёт не заменяет ручную цену. Подача и обратное такси сохраняются отдельно, остаток — оплата работы. После создания повышать цену можно только до назначения водителя, с журналом изменений.

Если обе стоимости такси неизвестны либо не помещаются в предложенную сумму, заказ сохраняется с неподтверждёнными расходами. Диспетчер в деталях карточки указывает две суммы; общая цена клиента сохраняется. До подтверждения принять/назначить заказ нельзя. Если суммы не хватает, нужно согласовать повышение цены с клиентом; приложение не увеличивает её самостоятельно. После подтверждения расходов отправляется уведомление допущенным водителям.

Комиссия резервируется и списывается только с оплаты перегона (итог минус две поездки на такси), по проценту пассажирской карточки водителя. Увеличение клиентской цены увеличивает оплату работы. После назначения разбивка и комиссия фиксируются. Старые диспетчерские заказы без `soberFare` сохраняют прежний порядок комиссии.

В пассажирской карточке водителя диспетчер включает «Трезвый водитель — допуск к перегону автомобиля клиента». Без допуска эти заказы не отображаются и уведомления не отправляются. Допуск относится к перегону автомобилей с обеими коробками; клиент обязательно указывает МКПП/АКПП и марку автомобиля. Водитель видит эти данные до приёма. Кабинеты со старой версией после обновления правил нужно перезагрузить.

## Подключение

Сайт публикуется через GitHub Pages. Firebase обновляется владельцем из Cloud Shell:

```bash
task_dir="$(mktemp -d)"
git clone --depth 1 https://github.com/TaxiUspeh/landing-.git "$task_dir/site"
bash "$task_dir/site/scripts/deploy-sober-driver.sh"
```

Скрипт сначала публикует Cloud Functions и Firestore Rules, затем включает `settings/soberDriverBooking.schemaVersion = 1`. До этого онлайн-отправка новой услуги закрыта. Скрипт не меняет заказы, балансы и тарифы остальных услуг. После успешного подключения обновите страницы и включите допуск нужным водителям.

## Проверка

`npm run check` проверяет тарифы, сохранение ручной цены, задержки геокодера, фильтрацию и уведомления. `tests/firestore/sober-ui.test.mjs` проверяет реальную форму и элементы диспетчера в DOM. Сценарии эмулятора в `tests/firestore/driver-finance.test.mjs` проверяют создание, допуск, подтверждение расходов, повышение цены, приём и завершение с правильной комиссией. Реальные клиентские заказы при проверке не создаются.
