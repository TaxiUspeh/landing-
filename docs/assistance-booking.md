# Онлайн-заказ помощи на дороге

Клиент выбирает тип помощи, указывает одно место (адрес вручную или точку на карте), телефон и предлагает целую сумму от 1 500 ₸. Для «Прочее» нужно описание задачи. Автоматического расчёта за километры нет. Ошибка геокодера не блокирует текстовый адрес.

Водитель принимает предложенную сумму. Пока идёт поиск, клиент может повысить цену или отменить заявку. После назначения действуют обычные правила отмены. Комиссия считается по ставке, зафиксированной при приёме, и списывается один раз при завершении.

Заявки и уведомления доступны только водителям с активным легковым направлением и отдельным допуском **«Помощь на дороге»** (`assistanceEnabled: true`). Диспетчер включает его в карточке легкового водителя. По умолчанию допуск выключен; водитель сам его включить не может. Это также касается ручного назначения заявок на помощь. Уже принятый заказ можно завершить при последующем снятии допуска.

Услуга использует существующий ID водителя и баланс. Данные автомобиля и задачи показаны в подробностях заказа. Навигация ведёт к месту помощи. Повтор из истории открывает форму помощи, где клиент заново проверяет тип задачи и цену.

## Подключение

В Cloud Shell из актуального репозитория:

```bash
bash scripts/deploy-assistance-booking.sh
```

Скрипт проверяет модули, публикует `functions:driver_push` и `firestore.rules`, затем устанавливает `settings/assistanceBooking.schemaVersion = 1`. До установки маркера онлайн-отправка закрыта. Общая настройка предложений цены `settings/customerPricing.enabled` должна быть включена, лимит — не ниже 1 500 ₸.

После сообщения «Помощь на дороге подключена» обновите страницы и включите допуск нужным водителям в панели диспетчера. Сам скрипт не меняет карточки водителей. Для грузоперевозок остаётся отдельный скрипт подключения.

## Проверка

- Модульные проверки: валидация типа/описания/цены, отдельный допуск, уведомления и навигация к одной точке.
- DOM: маркер подключения, обязательная цена, ручной адрес, сохранение выбранных данных до авторизации, текущий заказ и повтор из истории.
- Firestore Emulator: создание и отказ по неправильным данным, видимость и приём по допуску, повышение цены, отмена, заморозка цены при приёме, однократная комиссия и отсутствие самовольного включения допуска.
