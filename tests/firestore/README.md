Проверка онлайн-аукциона и завершения заказов выполняется только в локальном Firestore Emulator с демонстрационным project ID. Нужны Node.js 20/22 и Java 17.

Из этой папки выполните `npm install`, затем `npm test`. Набор проверяет создание заказа, приватность контактов и предложений, выбор по показанной цене, отзыв, срок предложения, занятость водителя, одновременные назначения, возврат в новый раунд и завершение с комиссией. После завершения проверяется возможность принять следующий заказ и запрет повторного начисления комиссии.

Для включения аукциона в рабочем приложении владелец проекта публикует **полное содержимое корневого `firestore.rules`** в Firebase Console: https://console.firebase.google.com/project/taxiuspeh-76d55/firestore/rules . Затем нужно обновить клиентское приложение и кабинет водителя. Дополнительный составной индекс для новых запросов аукциона не требуется. Существующие индексы истории и чата сохраняются.

В аукционе используется только онлайн-заказ. Свободный водитель отправляет цену и время подачи; предложение действует 2 минуты и может быть обновлено или отозвано. Клиент выбирает конкретное предложение. Атомарная запись закрепляет согласованную цену и переводит свободного водителя в занятое состояние. Другие предложения блокируются состоянием заказа; при занятости кабинет также отзывает предложения водителя. При возврате заказа в поиск начинается новый раунд, старые предложения не принимаются.

Данные переговоров: `orders` со статусом `bidding`, `proposedPrice`, `auctionRound`; `auctionOffers/{orderId}_{driverUid}` — одно предложение водителя на заказ. Комиссия 20% начисляется после завершения от сохранённого `priceAmount`. Для аукциона это выбранная цена, для обычного диапазона — прежняя верхняя сумма. Публикация сайта сама по себе не публикует правила Firebase. Уведомления об аукционе работают в открытом кабинете; фоновый FCM этой доработкой не развёртывается.

Категории автомобилей: универсал +20%, минивэн +50% к обычному тарифу. Каждая граница диапазона округляется вверх до 100 ₸. Надбавка применяется один раз после расчёта обычной цены, в том числе для межгорода и промежуточных остановок. Комиссия остаётся 20% от сохранённой верхней суммы.

Для включения категорий сначала опубликуйте полный `firestore.rules`. Затем в диспетчерской откройте карточки нужных водителей, отметьте «Универсал» / «Минивэн», укажите фактическое число пассажирских мест без водителя и сохраните. Для минивэна допустимо 5–8 мест. Существующие карточки сохраняют «Легковой»; категории по модели машины автоматически не назначаются.

Профиль водителя хранит `serviceCategories` и `passengerSeats`. Премиальный заказ такси хранит `vehicleCategory`, `passengerCount`, `basePriceMin`, `basePriceMax`. Обычные клиентские заказы могут сохраняться без новых полей и остаются совместимыми с прежними правилами. Новые правила проверяют категорию и вместимость при принятии и ручном назначении, а также согласованность надбавки и итоговой цены. Изменение категории после принятия не мешает завершить текущую поездку.

Список доступных заказов и сигналы в кабинете фильтруются по подходящей машине; контакты остаются закрытыми до назначения. Новые составные индексы для категорий не требуются. `npm test` из этой папки запускает проверки эмулятора и DOM интерфейса; `npm run check` из корня проверяет сайт, маршруты и расчёт категорий.
